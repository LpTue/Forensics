Quản lý tập trung tài liệu HackMD & Files

File Explorer (Đã sắp xếp A-Z)

Hướng dẫn sử dụng
  • Các thư mục và tệp được tự động sắp xếp A-Z, thư mục luôn hiển thị trước tệp.
  • Bấm vào Thư mục để mở/đóng.
  • Bấm vào Tên Tệp để mở bài viết trên HackMD ở tab mới.
Tip: Có thể tải thẳng file HTML này lên GitHub Pages để làm web cá nhân miễn phí!

Hướng dẫn thêm cấu trúc (Dành cho bạn)

1. Cách thêm Thư mục (Folder)

Copy đoạn code sau dán vào trong mảng children của nơi bạn muốn thêm. Hệ thống sẽ tự động sắp xếp vị trí.

{
    type: "folder",
    name: "Tên Thư Mục Mới",
    isOpen: true, // true = mở sẵn, false = đóng
    children: [
        // Khai báo các file hoặc folder con ở đây
    ]
}

2. Cách thêm Tệp (File) & Link

Thêm tệp mới vào trong children. Gắn link HackMD/Drive vào phần url.

{ 
    type: "file", 
    name: "ten-bai-viet.md", 
    url: "https://hackmd.io/link-cua-ban" 
}
